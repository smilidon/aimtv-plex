# AI MTV Plex 0.5.0 Alpha 1

First tagged prerelease of the Plex community fork of Decentricity/aimtv.
This is an **alpha**, not a production-readiness claim. The automated checks do not
include a real Plex server, NVIDIA GPU, model download or full inference render.

## Install

Use Python 3.10+ in a fresh virtual environment. The release wheel includes the
application, not FFmpeg, GPU drivers or inference model weights. Dependencies are
installed by pip; models are downloaded separately with consent.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install "aimtv-plex[plex] @ https://github.com/smilidon/aimtv-plex/releases/download/v0.5.0a1/aimtv_plex-0.5.0a1-py3-none-any.whl"
aimtv --version
```

The package distribution is now `aimtv-plex`; the executable and Python imports
remain `aimtv`. Do not install upstream `aimtv` and this fork into the same Python
environment because they own the same module paths and command. Existing media,
configuration and cache roots are unchanged.

The wheel and source distribution are attached with `SHA256SUMS`. These checksums
identify the exact release files; they are not an independent signature.
PyPI is a separate publishing destination: the `pypi` workflow job must succeed
before an index install such as `pip install "aimtv-plex[plex]==0.5.0a1"` is available.

## Included

- Plex music-section selection with CLI/environment configuration, local-file audio
  access, embedded-lyrics extraction and optional Genius fallback.
- Server-scoped lyric caches, stale/corrupt-cache recovery, retries after lyric
  misses, hash-checked cache metadata and atomic replacement.
- Source-aware lyric provenance, rejection of unknown lyric sources and omission of
  tokens from printable configuration representations.
- Correct concatenation of mixed PCM sample rates/channel counts; compatible PCM
  keeps the sample-preserving path and existing fade/crossfade rules.
- Zero-interstitial control and filesystem-order-independent seeded interstitial picks.
- Dedicated distribution name and a single authoritative version value.
- Automated Python 3.10/3.12 tests, real FFmpeg regression tests, static checks,
  distribution validation and clean-environment wheel/CLI smoke checks.
- A repeatable GitHub release and PyPI Trusted Publishing workflow.

## Plex playback

This is an external companion application, **not a Plex plugin or an official Plex
product**. Render an MP4 outside the watched library, then copy the completed file
into a Plex **Other Videos** library and scan it. See the README for details.

## Known limitations

- Rendering requires an NVIDIA GPU and local model files; FFmpeg/ffprobe must be on PATH.
- Airadio and its existing startup assets are still required in Plex mode.
- Plex media must be readable at the paths reported by the server; no streaming fetch.
- Sampling uses the first `max(100, song_count)` returned tracks, not the entire library.
- Embedded/Genius lyrics are source-traceable, not independently verified against audio.
- Do not run concurrent renders with the same AIMTV_HOME; staging files are shared.
- Full inference dependencies are not installed or exercised by the lightweight CI suite.

Upstream MIT license and Decentricity attribution are retained.
